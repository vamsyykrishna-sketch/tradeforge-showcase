# TradeForge - Project Vision

## Vision

TradeForge is a professional platform for building custom trading software.

The goal is to create robust, reliable and maintainable software for professional traders, HNIs and institutions.

The platform should support multiple types of trading applications including:

- Stock Screeners
- Trading Bots
- Alert Systems
- Execution Systems
- Portfolio Analytics
- Research Tools

Every application built on TradeForge should follow the same engineering standards, architecture and coding practices.

The first product built on this platform will be the Mark Minervini VCP Scanner.
